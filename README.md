# 中学受験 漢字トレーニング

中学受験に向けて、漢字の読み書きや語句の意味を毎日練習できる、シンプルなブラウザー向け学習サイトです。読み問題と書き問題を各10問ずつ出題し、解答・解説を確認しながら学習できます。

## 特長

- **読み問題10問・書き問題10問**を表示します。
- 難読漢字、日本文化、四字熟語、故事成語、ことわざ、慣用句の問題を収録しています。
- 解答は「解答・解説を見る」を開いて確認できます。問題に関連するWikipediaと画像検索へのリンクも利用できます。
- その日の問題セットは日付をもとに選ばれ、「練習問題を作り直す」を押すと別のセットに切り替わります。
- PC・スマートフォンの画面幅に合わせて表示します。

## 使い方

### ブラウザーで開く

`index.html` と問題データのJSONファイルを同じ場所に置き、Webサーバー経由で `index.html` を開いてください。問題データはJavaScriptの`fetch`で読み込むため、`file://`で直接開くのではなく、HTTP経由でのアクセスが必要です。

Python 3がインストールされている場合は、リポジトリのディレクトリで次のコマンドを実行します。

```bash
python3 -m http.server 8000
```

ブラウザーで <http://localhost:8000/> を開きます。終了するときはターミナルで `Ctrl+C` を押してください。

## GitHub Pagesで公開・非公開にする

このサイトはビルド工程のない静的サイトです。GitHub Pagesでは、リポジトリの`index.html`と問題データJSONを使って公開できます。

### GitHub Pagesで公開する

1. GitHubでこのリポジトリを開き、上部の **Settings** を選択します。
2. 左側メニューの **Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. **Branch** で公開するブランチ（通常は`main`）とフォルダー（通常は`/(root)`）を選択し、**Save** を押します。
5. Pagesの設定画面に表示されるサイトのURLを開いて、公開を確認します。反映には数分かかることがあります。

`index.html`および6つの問題JSONファイルは、同じ公開元ディレクトリに置いてください。GitHub Pagesの公開URLは、ソースリポジトリがPublicなら誰でも閲覧できます。

### GitHub Pagesサイトだけを非公開にする（公開解除）

サイトの公開を解除しても、リポジトリの公開範囲やファイルには影響しません。ソースコードは引き続き閲覧可能です。

1. リポジトリのメインページ（`https://github.com/yysaitoyy1979/kanji-quiz`）で **Settings** を開きます。
2. 左側の **Pages** を選択します。
3. Pagesの設定に表示される公開サイトの欄で **…** を選び、**Unpublish site** をクリックして確定します。

公開を解除すると現在のデプロイが削除され、サイトにアクセスできなくなります。再公開するには、Pagesの設定で公開元のブランチとフォルダーを設定し直してください。

### リポジトリ自体を非公開にする

リポジトリをPrivateにすると、ソースコードとファイルを閲覧できる人が制限されます。**リポジトリをPrivateにする操作と、Pagesサイトの公開解除は別の設定です。** GitHubのプランやPagesの公開設定によってサイトの公開可否が異なるため、リポジトリの公開範囲を変更する前にGitHub Docsで現在の仕様を確認してください。サイトも公開停止したい場合は、上記の手順で先にPagesの公開を解除します。

1. リポジトリのメインページで **Settings** を開きます。
2. **General** のページ末尾にある **Danger Zone** を開きます。
3. **Change repository visibility** から **Change visibility** を選択し、**Make private** を選んで確認します。

Privateに変更すると、招待されたコラボレーター以外は通常リポジトリを閲覧できなくなります。公開済みの情報や過去に第三者が取得したコピーまで回収できるわけではありません。公開履歴にパスワードやトークンなどの秘密情報が含まれていた場合は、リポジトリを非公開にするだけでなく、その認証情報を失効・変更してください。

### リポジトリを再び公開する

1. リポジトリの **Settings → General → Danger Zone** を開きます。
2. **Change repository visibility** から **Change visibility** を選択し、**Make public** を選んで確認します。
3. GitHub Pagesも公開する場合は、**Settings → Pages** で公開元のブランチとフォルダーを設定し、デプロイが完了したら表示されたURLを確認します。

Publicに戻す前に、公開して問題のない内容だけがコミット履歴やファイルに含まれていることを確認してください。

## ファイル構成

```text
.
├── index.html                 # 画面、スタイル、クイズの表示・出題処理
├── questions_kanji.json       # 難読漢字
├── questions_japan.json       # 日本文化
├── questions_yojijukugo.json  # 四字熟語
├── questions_kojiseigo.json   # 故事成語
├── questions_kotowaza.json    # ことわざ
└── questions_kanyouku.json    # 慣用句
```

各問題データはJSON配列で、問題ごとに`id`、`category`、`kanji`、`reading`、`description`を持ちます。`index.html`が6つのJSONファイルを読み込んで一覧にまとめ、そこから20問を選んで読み・書きの問題に振り分けます。

## 技術構成

- HTML、CSS、JavaScript（外部ライブラリーやビルドツールは不要）
- 問題データ：JSON

## 問題データの編集

問題を追加・修正する場合は、該当する`questions_*.json`を編集してください。各要素は次の形式です。

```json
{
  "id": "example",
  "category": "難読漢字",
  "kanji": "木漏れ日",
  "reading": "こもれび",
  "description": "木々の間から差し込む光。"
}
```

問題を読み込めない場合は、JSONの構文とファイル名を確認し、`index.html`と同じディレクトリからHTTP経由でサイトを開いていることを確認してください。
